Python version requirements
===========================

The current pyparsing release requires Python 3.9 or later. The minimum
version is also declared in ``requires-python`` in ``pyproject.toml``.

For older Python environments, use a compatible pyparsing release:

.. list-table::
   :header-rows: 1

   * - pyparsing version
     - Required Python
   * - 3.3.0 and later
     - 3.9 or later
   * - 3.2.0 - 3.2.4
     - 3.9 or later
   * - 3.0.8 - 3.1.4
     - 3.6.8 or later
   * - 3.0.0 - 3.0.7 (these versions are discouraged)
     - 3.6 or later
   * - 2.4.7
     - 2.7 or later
   * - 1.5.7
     - 2.6 - 2.7
